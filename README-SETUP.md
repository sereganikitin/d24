# ds24-kiosk

Android-приложение "инфопанель" для входной группы ЖК: открывает веб-версию
личного кабинета Диспетчер24 (`lk.purehome.ru`) в альбомном полноэкранном
kiosk-режиме, не даёт экрану гаснуть и не даёт выйти из приложения.

Два варианта сборки (build flavor `mode`):

- **dev** — для тестирования на личном телефоне. Не перехватывает кнопку
  Home, не запускается автоматически после перезагрузки, не ставится в
  Screen Pinning автоматически. `applicationId` — `ru.uk.ds24kiosk.dev`,
  ставится рядом с боевой сборкой, не конфликтует с ней.
- **kiosk** — боевая сборка для планшета на входе. Полный набор: landscape +
  fullscreen + Screen Pinning + автозапуск после перезагрузки + замена
  Home-экрана + автоперезапуск при крэше.

## Сборка APK через Codemagic (без Android Studio на этом компьютере)

В проекте уже есть `codemagic.yaml` и рабочий Gradle wrapper (скачан
официальный `gradle-wrapper.jar`, не сгенерирован вручную) — сборка в
облаке настроена и готова.

1. Создать репозиторий на GitHub (или GitLab/Bitbucket, если Codemagic у
   вас подключён к нему) и запушить туда этот проект. На этом компьютере
   для GitHub нет рабочего SSH-ключа (проверено — есть ключи только под
   другие серверы), так что проще всего через HTTPS:
   ```
   git remote add origin https://github.com/<ваш-логин>/ds24-kiosk.git
   git push -u origin main
   ```
   При пуше Git спросит логин/пароль — вместо пароля нужен Personal
   Access Token (GitHub → Settings → Developer settings → Personal
   access tokens → Fine-grained token с правом Contents: Read and write
   на этот репозиторий).
2. В Codemagic: Add application → выбрать этот репозиторий. Codemagic
   сам увидит `codemagic.yaml` в корне и предложит workflow
   `ds24-kiosk-debug`.
3. Запустить сборку (Start new build). По готовности в интерфейсе
   Codemagic появится ссылка на артефакты — два APK:
   `app-dev-debug.apk` (для теста на личном телефоне) и
   `app-kiosk-debug.apk` (боевой вариант для планшета). Также придёт
   письмо на почту с уведомлением о готовности сборки.
4. Скачать `app-dev-debug.apk` на телефон и установить (может
   понадобиться разрешить установку "из неизвестных источников").

Дальше при каждом изменении кода: закоммитить, `git push`, запустить
сборку в Codemagic заново (или настроить автосборку по пушу в
Codemagic → Workflow settings → Triggering).

## Открыть проект в Android Studio (если всё же понадобится)

Открыть папку `ds24-kiosk` в Android Studio (File → Open). При первом
Sync студия предложит скачать недостающие компоненты SDK (compileSdk 34) —
согласиться. Если студия предложит миграцию AGP/Gradle на более новую
версию — соглашаться безопасно, проект не завязан на конкретный патч.

Собрать/запустить нужный вариант: `Build Variants` → выбрать `devDebug`
(для теста на своём телефоне) или `kioskDebug`/`kioskRelease` (для
планшета).

## Тест на своём смартфоне (без физического доступа к планшету)

1. Выбрать `devDebug`, запустить на телефоне.
2. Приложение откроется в альбомной ориентации на весь экран, экран не
   будет гаснуть, пока открыто приложение.
3. Пройти вход по номеру телефона + SMS-код от сервисного аккаунта УК —
   проверить, что после перезапуска приложения сессия сохраняется
   (повторный вход не требуется).
4. Долгий тап (3 сек) в правом нижнем углу экрана → диалог с ПИН
   (по умолчанию `2468`, см. `ADMIN_PIN` в `app/build.gradle.kts`) → меню
   обслуживания (обновить страницу / Wi-Fi / вернуться в киоск-режим).
5. В `devDebug` кнопка Home и системная навигация работают как обычно —
   специально не блокируются, чтобы не мешать личному телефону.

## Установка на планшет в лобби (когда будет физический доступ)

1. Собрать `kioskRelease`, установить APK.
2. Разрешить игнорировать оптимизацию батареи (появится системный запрос
   при первом запуске), в системных настройках экрана выставить
   максимальный таймаут блокировки/"никогда".
3. Через админ-жест (см. выше) один раз пройти вход по телефону+SMS от
   сервисного аккаунта УК.
4. При первом `startLockTask()` система может показать диалог
   подтверждения Screen Pinning — подтвердить один раз.
5. Проверить: перезагрузка планшета → приложение поднимается само в
   альбомном режиме, кнопки Back/Overview/Home не дают выйти.
6. Если нужно снять киоск полностью (перепрошивка, обновление ОС) —
   админ-жест → ПИН → "Вернуться в киоск-режим" не выбирать, вместо этого
   долгим удержанием Back+Overview снять системный Screen Pinning (либо
   через ADB `adb shell am task lock stop`, если есть доступ).

## Известные ограничения этой версии

- Без Device Owner Screen Pinning менее надёжен, чем полноценный kiosk
  через MDM: теоретически пользователь может выйти через комбинацию
  системных жестов (удержание Back+Overview), это стандартное системное
  поведение Android, отключить которое можно только через Device Owner.
- Автологин по SMS не автоматизирован (не читаем SMS) — вход выполняется
  вручную один раз через админ-меню сотрудником УК.
- Голосовой ИИ-агент и умный дом не реализованы — в коде оставлена точка
  расширения (`webview/AndroidBridge.kt`, JS-мост `window.DS24Kiosk`) для
  следующего этапа.
